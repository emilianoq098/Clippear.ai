# Proyecto: Clipper.ai v3

- Producto para encontrar, editar y publicar video/audio que el usuario ya tiene, además de foto → video.
- Los originales no se sobrescriben; ediciones y exports se versionan.
- El procesamiento desde redes sociales no usa scraping ni descarga; admite archivo, URL directa a archivo y OAuth oficial.
- La fase vigente es Fase 0 — cimientos y portada; no iniciar Fase 1 sin confirmación.
