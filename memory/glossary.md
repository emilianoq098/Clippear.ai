# Glosario de Clipper.ai v3

- **Asset:** archivo original o derivado (proxy, miniatura, clip exportado).
- **BYOK:** Bring Your Own Key; el usuario conecta una clave propia que se guarda cifrada en backend.
- **Candidate:** segmento temporal propuesto para puntuación antes de mostrarse como clip.
- **Clip:** selección de uno o más segmentos de un asset fuente para compartir.
- **EDL:** Edit Decision List; lista versionada de cortes, pistas, transformaciones y capas.
- **Highlight:** momento relevante detectado en audio/video con intervalo, puntaje y explicación.
- **Job:** trabajo asíncrono reanudable, como analizar un archivo o renderizar una EDL.
- **Mock provider:** proveedor simulado que devuelve contratos realistas sin una clave real.
- **Proxy:** copia de menor resolución usada para previsualización y análisis eficiente.
- **RLS:** Row-Level Security; políticas que aíslan registros por workspace en la base de datos.
- **Signal:** observación con timestamp, como palabra, pico de energía, escena, rostro u OCR.
- **STT:** Speech-to-Text; transcripción de voz con marcas de tiempo y, opcionalmente, hablantes.
- **Workspace:** espacio con miembros, proyectos, permisos y consumo compartido.
